# Install your GitHub profile README

1. Open https://github.com/ishikasinhaa
2. Create (or open) the public repository named exactly `ishikasinhaa`.
3. Replace its `README.md` with the `README.md` in this folder.
4. Upload the `assets/` folder alongside the README. Keep the path exactly:
   `assets/ishika-lavender-banner.png`
5. Commit the changes. GitHub will render the README on your profile.

## Before publishing

- Replace the LinkedIn placeholder with your actual profile URL.
- Add your preferred public email address in the mailto link, or remove the email badge.
- Confirm that each linked repository is the right project and that the descriptions reflect your exact contribution.
- The Upcharr repository currently appears as a fork. Keep that attribution transparent.
- External stats cards and typing SVG rely on third-party services and may occasionally be unavailable.
- Skill icons are illustrative. Remove any tool you have not used or are not actively exploring.
